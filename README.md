Expense Ledger

A small, no-framework expense tracker styled like a paper ledger book — deep ink green, warm paper background, and monospace numbers so amounts actually line up. Built with plain HTML, CSS, and JavaScript.

Features
Log an entry as Spent or Received with a description and amount
Running balance updates instantly, with separate totals for money in and out
Remove any single entry, or clear the whole ledger
Responsive layout, keyboard-accessible controls, and reduced-motion support
Zero dependencies, zero build step — just open the HTML file


Tech stack
HTML5
CSS3 (custom properties, CSS Grid)
Vanilla JavaScript (DOM APIs, no libraries)
